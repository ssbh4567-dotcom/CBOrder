# Reproducible Penalized Power Plots

This folder contains the MATLAB codes used to reproduce the penalized power plots presented in the manuscript. Five R script  generates the associated penalized power figure reported in the simulation study of the manuscript.

## Files

The folder includes the following MATLAB scripts:

- `Penalized_Power_Plot_1.m` – MATLAB code for the penalized power plot -- Figure 3 of manuscript.
- `Penalized_Power_Plot_2.m` – MATLAB code for the penalized power plot -- Figure 4 of manuscript.
- `Penalized_Power_Plot_3.m` – MATLAB code for the penalized power plot -- Figure 5 of manuscript.
- `Penalized_Power_Plot_4.m` – MATLAB code for the penalized power plot -- Figure 6 of manuscript.
- `Penalized_Power_Plot_5.m` – MATLAB code for the penalized power plot -- Figure 7 of manuscript.

## Usage

Each MATLAB script is self-contained and can be executed independently. Open the desired `.m` file in MATLAB and run the script to reproduce the corresponding penalized power plot. The scripts generate the figures using the simulation results reported in the manuscript.

## Requirements

- MATLAB.

## Notes

These scripts are provided to facilitate the reproducibility of the simulation results and figures presented in the manuscript. They are intended solely for reproducing the corresponding penalized power plots.

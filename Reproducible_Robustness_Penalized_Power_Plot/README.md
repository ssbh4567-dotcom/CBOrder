# Reproducible Robustness Penalized Power Plots

This folder contains the MATLAB codes used to reproduce the robustness penalized power plots presented in the Supplementary. Five MATLAB scripts generate the associated robustness penalized power figures plotted in the supplementary.

## Files

The folder includes the following MATLAB scripts:

- `Robustness_CBLRT.m` – MATLAB code for the robustness penalized power plot of the CBLRT (Figure S7.1).
- `Robustness_CBMax.m` – MATLAB code for the robustness penalized power plot of the CBMax test (Figure S7.2).
- `Robustness_CBMin.m` – MATLAB code for the robustness penalized power plot of the CBMin test (Figure S7.3).
- `Robustness_CBMaxMin.m` – MATLAB code for the robustness penalized power plot of the CBMaxMin test (Figure S7.4).
- `Robustness_CBMinMax.m` – MATLAB code for the robustness penalized power plot of the CBMinMax test (Figure S7.5).

## Usage

Each MATLAB script is self-contained and can be executed independently. Open the desired `.m` file in MATLAB and run the script to reproduce the corresponding robustness penalized power plot. The scripts generate the figures using the simulation results under different non-normal distributions reported in the manuscript.

## Requirements

- MATLAB.

## Notes

These scripts are provided to facilitate the reproducibility of the robustness simulation results and figures presented in the supplementary of the main manuscript. They are intended solely for reproducing the corresponding robustness penalized power plots.

# MCSE_Computational_Cost_Sensitivity

This folder contains four R scripts that reproduce the Monte Carlo standard error (MCSE), computational cost, and sensitivity analyses reported in the paper (Tables 4–7) and its supplementary material (Tables S2.1 and S3.2).

## Contents (in manuscript table order)

| Order | Script | Reproduces |
|---|---|---|
| 1 | `MCSE_Sensitivity.R` | Tables 4–5 (MCSE for size and power) |
| 2 | `Computational_Cost.R` | Table 6 (runtime benchmark) |
| 3 | `MCSE_Sensitivity.R` (same script, later section) | Table 7 (sensitivity to bootstrap replications M) |
| S1 | `Sensitivity_Eq_2_5.R` | Table S2.1 (supplementary — MLE uniqueness condition, Eq. 2.5) |
| S2 | `Sensitivity_of_Algorithm_1.R` | Table S3.2 (supplementary — sensitivity of Algorithm 1 to initialization) |

**Note:** `MCSE_Sensitivity.R` produces both Tables 4–5 and Table 7 within a single script — Table 6 (from `Computational_Cost.R`) falls *between* them in the manuscript, but is generated by a separate file. Run `MCSE_Sensitivity.R` and `Computational_Cost.R` independently; they do not depend on each other.

## Requirements

* R (version used for the paper: 4.3.3)
* Packages:
  * `CBOrder` — required only for `Computational_Cost.R`; installed automatically from GitHub if missing:
    ```r
    remotes::install_github("ssbh4567-dotcom/CBOrder", force = TRUE)
    ```
  * `Iso`, `parallel`, `doParallel`, `foreach` — required for `MCSE_Sensitivity.R` and `Sensitivity_of_Algorithm_1.R`; installed automatically if missing
  * `Sensitivity_Eq_2_5.R` uses base R only
* Multiple CPU cores recommended for `MCSE_Sensitivity.R` (manuscript used 64 cores)

## Data

No external data files are used anywhere in this folder — all four scripts simulate their own data internally (via `rnorm`), with fixed seeds (`456` throughout) for reproducibility.

---

## 1. `MCSE_Sensitivity.R` — Tables 4, 5, and 7

Reproduces the MCSE analysis for empirical size and power (Tables 4–5), and the sensitivity of empirical size to the number of bootstrap replications M (Table 7), for the five complete bipartite tests (`CB_LRT`, `CB_Max`, `CB_Min`, `CB_MaxMin`, `CB_MinMax`).

**What it does:**
1. Defines self-contained versions of the five tests, each running `Q` outer Monte Carlo repetitions and `M` inner bootstrap repetitions in parallel.
2. **MCSE for size** (Table 4): runs all five tests under the null (equal means) across two variance configurations.
3. **MCSE for power** (Table 5): runs all five tests under low- and high-power mean configurations.
4. **Sensitivity to M** (Table 7): re-runs empirical size for `M = 500, 1000, 2000, 3000, 4000, 5000` (with `Q = 5000` fixed).

**Key settings:** `M` and `Q` default to 100 for quick testing; set both to 5000 to exactly reproduce the manuscript. `CORE <- parallel::detectCores() - 1` by default (manuscript used 64).

**Runtime:** quick with defaults (`M = Q = 100`); with `M = Q = 5000` can take **hours to days** even with parallelization.

**Output:** console-only — test name, estimated size/power, and MCSE for each scenario.

---

## 2. `Computational_Cost.R` — Table 6

Benchmarks execution time only (no test statistics) for the five tests as the number of treatment levels `p` increases.

**What it does:** for `p = 4, 8, 12, 16, 20`, simulates `p` groups (`rnorm(50, 0, 4)`) and times `CBLRT`, `CBMax`, `CBMin`, `CBMaxMin`, `CBMinMax` (`alpha = 0.05`, `k0 = 2`, 100,000 bootstrap resamples), printing only elapsed time in minutes.

**Runtime:** system-dependent; per the paper, ~0.60 min per pairwise test and ~3.0 min for `CBLRT` at `p = 4`, rising to ~4.0 min and ~7.0 min respectively at `p = 20`. All five `p` values together can take roughly an hour.

**Output:** console-only — elapsed time (minutes) per test per `p`. No test statistics or p-values are returned (`invisible()`).

---

## 3. `Sensitivity_Eq_2_5.R` — Table S2.1 (supplementary)

Monte Carlo check of how often the data-dependent MLE uniqueness condition (Equation 2.5) holds under the Complete Bipartite (CB) order restriction.

**What it does:** for `M = 10,000` replications per scenario, generates data, computes the MLE variance and means for each group, and checks whether Eq. 2.5 is satisfied for every group. Repeats across 16 scenarios (`p = 6` or `8`; homo-/heteroscedastic; balanced/unbalanced; small/moderate sample sizes), matching Table S2.1.

**Runtime:** short — seconds to a couple of minutes.

**Output:** console-only — one-row data frame per scenario with `Groups`, `Total_Simulations`, `Times_Condition_Held`, and `Equation_2.5_satisfied`.

---

## 4. `Sensitivity_of_Algorithm_1.R` — Table S3.2 (supplementary)

Checks whether Algorithm 1 (the CB MLE iterative fit) converges to the same solution regardless of starting values, by comparing an unconstrained-MLE initialization against a randomly perturbed one.

**What it does:** for `Q = 10,000` replications per scenario, generates data, runs Algorithm 1 from a baseline initialization and again from a perturbed one, then checks if both converge to the same solution (within `1e-4`). Repeats across the same 16 scenarios as above, matching Table S3.2.

**Runtime:** a few minutes.

**Output:** console-only — one-row data frame per scenario with `Groups`, `Total_Simulations`, `Times_Matched`, and `Identical_sol`.

---

## How to run

Each script is self-contained and can be run independently in R/RStudio (source the full file). There is no required run order between scripts, except that `MCSE_Sensitivity.R` internally must be run top-to-bottom in one session since later sections reuse objects defined earlier in the same file.

## Notes

* All four scripts use `set.seed(456)` for reproducibility.
* Default parameter values (`M`, `Q`, `CORE`) in `MCSE_Sensitivity.R` are set low for fast testing; increase to the manuscript's values (`M = Q = 5000`, `CORE = 64`) for exact reproduction, noting the substantially longer runtime.
* Scenario definitions (sample sizes, means, standard deviations) in `Sensitivity_Eq_2_5.R` and `Sensitivity_of_Algorithm_1.R` are hardcoded to match their respective supplementary tables exactly.
